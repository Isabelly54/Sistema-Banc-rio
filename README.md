# Sistema Bancário | DIO

Este projeto tem por objetivo, realizar um simples sistema bancário.

Atualmente, o sistema apresenta duas versões:

## Versão 1.0: 
A primeira versão representa um sistema bancário simples, utilizando de condicionais para alnaçar seus resultados.

- O Sistema é composto por três opções: 
 - Depósito: É possível realizar depósitos de qualquer valor, desde que não seja negativo.
 - Saque: A opção é disponível, desde que o saque não ultrapasse o valor de R$ 500,00 e nem o valor do saldo disponível. Além disso, é apenas possível realizar 3 saques diários de no máximo R$ 500,00.
 - Extrato: Onde será visualizado todas as movimentações do usuário.

## Versão 2.0:
A última versão representa a evolução do projeto.
Agora, as opções do sistema são representadas como funções, delimitando melhor suas funcionalidades e condicionais.

- O Sistema continua com suas funções anteriores e outras duas novas funções:
- Criar Conta: Permite a criação de uma conta do funcionário que irá sacar ou depositar um valor no banco.
- Usuário: Habilita o acesso as outras funções, caso já tenha uma conta criada.
